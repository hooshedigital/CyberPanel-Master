# حالت origin پشت TLS برای Apache

در حالت پیش‌فرض private HTTP تغییری رخ نمی‌دهد. گزینه صریح root-only --tls-origin در plan/apply موتور Apache، متغیرهای FastCGI HTTPS=on و SERVER_PORT=443 را ثابت می‌کند. این حالت فقط برای برنامه‌ای است که مالک آن را پشت TLS gateway قرار می‌دهد؛ درخواست مستقیم خصوصی نیز عمداً HTTPS فرض می‌شود. هدرهای جعلی X-Forwarded-Proto همچنان حذف می‌شوند؛ به هدر ورودی برای تشخیص HTTPS اعتماد نمی‌شود. این گزینه TLS واقعی ایجاد نمی‌کند، frontend یا گواهی را نصب نمی‌کند و یک مجوز عمومی نیست. برای FrankenPHP رد می‌شود. برنامه‌های موجود مهاجرت خودکار ندارند. آزمون PHP، POST، Host/SNI و رفتار redirect/session واقعی پیش از انتشار عمومی لازم است. Feast خارج از محدوده است.
