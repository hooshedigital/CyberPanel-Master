# Capacity Advisor + Docker retention review
گزارش read-only در داشبورد مرکزی و Create Website، با خواندن فایل aggregate root-owned و محدودیت freshness (۱۵ دقیقه ظرفیت، ۹۰ دقیقه Docker). هیچ فرمان Docker از Django یا قابلیت اجرایی ندارد. شمار تصاویر به‌صورت unique ID شامل all images است؛ تمام کانتینرهای متوقف و فعال برای references لحاظ شده‌اند؛ تمام تصاویر برچسب‌دار حفظ و سایر تصاویر فقط برای بررسی دسته‌بندی می‌شوند. نه prune، نه حذف، نه محاسبه قطعی فضای آزادشدنی. اسکن دوره‌ای یک ساعت، با timeout و محدودیت منابع. نسخه زنده پنل ممکن است با branch متفاوت باشد؛ stage_capacity_panel_overlay.py فقط چهار درج محدود را روی نسخه نصب‌شده در review copy انجام می‌دهد. بدون overwrite داشبورد موجود، بدون دسترسی به فایل مشتری/Feast.
