# جداسازی دایرکتوری پروژه برای موتورهای مستقل
در کنار جداسازی سوکت، مسیر حساب پروژه و public هر دو باید root-owned، گروه اختصاصی همان حساب و mode=0750 باشند. حساب باید shell غیرفعال و گروه هم‌نام داشته باشد؛ گروه مشترک و سایر اعضای گروه رد می‌شوند. قبل از prepare/start، مالک سرور محتوای برنامه را با مجوزهای فقط‌خواندنی و مالکیت مناسب قرار دهد؛ symlink و محتویات برنامه جداگانه ممیزی شوند. مسیرهای ثابت زیر /srv/hoosh-apache و /srv/hoosh-frankenphp. تغییر مالکیت روی سایت موجود خودکار نیست. این شرط برای پروژه‌های جدید private backend است، نه اثبات امنیت همه اجزای یک سایت عمومی. ثبت root-only، بدون web-to-root. برای frontend مشترک و TLS هنوز نیاز به طراحی و تأیید است.
