# Infrastructure 2027 — Preview 3

بخش فقط‌خواندنی Hoosh Web Engine Manager در مسیر Create Website به پنل نصب شد. این بخش فقط برای مدیر نمایش داده می‌شود و وضعیت RAM، Swap، دیسک و CPU/memory PSI60 را از خود سیستم می‌خواند. پیکربندی قبلی ساخت سایت و شرط تجاری بدون تغییر باقی مانده‌اند.

- فایل‌های جدید مطابق commit be6d58c644c34badbecce393b3a5dd5ed2d3226b نصب شدند.
- کنترل حداقلی پس از نصب: parsing سورس Python، بارگذاری template و render مستقل برای مدیر/غیرمدیر موفق بود؛ صفحه ورودی پنل و دو سایت نمونه HTTP 200، سرویس‌های اصلی فعال.
- خود پنل یک بار restart شد؛ وب‌سرور سایت‌ها restart نشد. بکاپ محلی و مسیر rollback محفوظ.
- آزمون مرورگر با نشست واقعی مدیر در این مرحله انجام نشد؛ صحت نمایش از آزمون template است.
- هیچ موتور جدیدی از فرم ایجاد نمی‌شود. Apache/FPM در staging، FrankenPHP و Valkey هنوز عملیاتی نشده‌اند. کش ترکیبی غیرفعال باقی می‌ماند.
- کرنل HWE 6.8 نصب شده ولی فعال‌سازی به ریبوت برنامه‌ریزی‌شده نیاز دارد؛ MGLRU/ZSWAP جدید هنوز فعال نشده‌اند. Buildx و Live Restore آماده، فضای دیسک همچنان هشدار دارد.

این انتشار توسعه‌ای است؛ نه تأیید نهایی provisioning یا استقرار همه فناوری‌ها.
