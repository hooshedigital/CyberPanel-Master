# استقرار سیاست محدودیت لاگ Stage — ۲۷ نوامبر ۲۰۲۶
ابزار compose_log_policy.py با چهار آزمون محلی و CI مستقل موفق، فقط logging پنج سرویس دو Compose Stage را اضافه کرد: Talent (database/web) و CyberPanel Stage (db/panel/watchdog). نسخه قدیم/جدید با Git blob fingerprint بررسی شد، مقایسه YAML فقط تغییر logging را پذیرفت و اصل فایل‌ها با mode/owner اصلی و نسخه پشتیبان خصوصی حفظ شدند. سیاست json-file max-size 10m max-file 3 است. هیچ کانتینری recreate/restart نشده؛ 18 شناسه فعال قبل و بعد ثابت؛ 8/8 diagnostic موفق. این سقف هنگام deployment/recreation بعدی اعمال می‌شود، نه روی کانتینرهای کنونی. مصرف دیسک 88%؛ فضای جدیدی آزاد نشد. هیچ تولید، Feast، پارسا، DB، پشتیبان یا image تغییر نکرد. نسخه‌های Compose محلی به source repo تأییدشده نگاشت نشدند؛ تغییر ممکن است در deployment آینده overwrite شود و باید با سورس اصلی sync شود. ابزار و قرارداد در GitHub منتشر شدند؛ هیچ محتوای Compose یا credential منتقل نشده است.
CI عمومی UI یک خطای import yaml داشت، چون suite جدید از PyYAML استفاده می‌کند؛ dependency همان نسخه pinned در workflow عمومی اضافه شد. اصلاح fixture interpolation قبل از استقرار انجام شد؛ نتیجه CI بعد از اصلاح باید بررسی شود.
