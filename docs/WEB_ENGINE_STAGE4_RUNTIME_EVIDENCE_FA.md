# شواهد مرحله چهارم — ۲۶ نوامبر ۲۰۲۶

مولد مستقل پیکربندی مرحله چهارم به شاخه آزمایشی اضافه شد. نسخه آزموده‌شده 05673e15defe99fa8cf56457e86ae3a26a6805ae است.

- ۱۷ آزمون هدفمند (۱۰ آزمون قبلی و ۷ آزمون جدید) در اجرای نهایی موفق. اجرای نخست دو خطای نبود فایل‌های کمکی overlay داشت؛ با تکمیل fixture رفع شد.
- مولد شش فایل config و manifest دارای SHA256 تولید کرد. Apache configtest و هر دو PHP-FPM configtest موفق بودند.
- بسته PHP-FPM 8.1 Ubuntu با هش تأییدشده فقط استخراج شد؛ هیچ بسته‌ای نصب نشد. نسخه صرفاً آزمایشی است.
- اجرای Apache و دو PHP-FPM با پیکربندی تولیدشده، UIDهای جداگانه، سوکت یونیکس و شبکه خصوصی: هر دو سایت فایل خصوصی خود را خواندند و خواندن فایل/سوکت دیگری رد شد.
- فایل .htaccess، فایل source.php.bak، symlink و source.PHP برای هر دو سایت با 403 رد شدند و سورس PHP منتشر نشد. Host ناشناخته در Apache نیز 403.
- تمام پردازش‌ها، سوکت‌ها، listenerهای آزمایش و fixtureهای موقت پاک شدند. سرویس‌های اصلی و سایت‌های مانیتورشده فعال بودند؛ OOM صفر.
- اجرای واقعی config جدید OLS هنوز انجام نشده است؛ زنجیره OLS در مرحله سوم با تنظیمات دستی آزموده شده بود.
- .htaccess مشتری عمداً در مولد غیرفعال است تا قواعد قابل ویرایش tenant مسیر proxy و handler را دور نزنند. فعال‌سازی محدود و آزموده نیازمند مرحله جداست.
- این مولد نه تراکنش provisioning است، نه مجوز اجرا و نه انتشار Production. فرم اصلی همچنان بدون تغییر است. HTTPS، Host/SNI/header و cache privacy، RBAC/CSRF، مالکیت واقعی tenant، rollback و load test باقی مانده‌اند.
