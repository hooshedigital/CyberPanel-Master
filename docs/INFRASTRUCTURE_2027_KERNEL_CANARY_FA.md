# فعال‌سازی کنترل‌شده کرنل HWE
۲۶ نوامبر ۲۰۲۶. پیش از ریبوت، GRUB و initramfs هر سه کرنل بررسی شدند. درایورهای ضروری virtio و ext4 در 6.8 داخلی هستند. قفل‌های apt/dpkg آزاد، سرویس‌های اصلی فعال، 18 کانتینر با سیاست unless-stopped و مانیتور سایت healthy. هفت واحد failed قبلی در baseline محلی ثبت شده‌اند.
- بوت یک‌باره 6.8.0-149-generic آماده؛ پیش‌فرض 5.15.0-202-generic تا تأیید بوت جدید حفظ شده. منوی GRUB پنج ثانیه. بکاپ محلی grub.cfg و grubenv و شناسه بوت/کانتینرهای قبل ثبت شده.
- اگر kernel hang رخ دهد، one-shot به خودی خود reboot نمی‌کند. از کنسول مستقل ارائه‌دهنده reboot و انتخاب کرنل قبلی؛ دسترسی به کنسول از MCP آزموده نشده است. مالک قبلاً تأیید ریبوت و امکان کنسول را داده است.
- بعد از بوت، uname، boot ID، MGLRU، zswap، Swap، سرویس‌ها، شمارش و سلامت کانتینرها، WordPress cache و HTTP عمومی بررسی شوند. تنها پس از تأیید، پیش‌فرض کرنل جدید شود.
- LZO حفظ شده؛ ZSTD به ارزیابی جدا نیاز دارد. Apache و FrankenPHP خصوصی آزموده شده‌اند، ولی provisioning عمومی و فرم Create Website هنوز کامل نیستند. Ubuntu جدید نیاز به مهاجرت مستقل دارد. این تغییر پایان مرحله فعال‌سازی کرنل نصب‌شده است، نه اعلام تکمیل همه توسعه‌ها.
- وضعیت این سند PRE-REBOOT است؛ موفقیت بوت هنوز تأیید نشده.
