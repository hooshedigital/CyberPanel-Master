# اعتبارسنجی زیرساخت نصب‌شده — ۲۶ نوامبر ۲۰۲۶

- نسخه‌های OLS 1.9.4، PHP 8.4.28 و 8.5.13، Buildx 0.30.1 و HWE 6.8.0-149 بررسی شدند. کرنل در زمان آزمون 5.15.0-202 بود. ZSWAP zsmalloc/LZO. فایل‌های بوت و GRUB معتبر، دو fallback محفوظ. dpkg --audit خالی.
- هر 18 کانتینر فعال سیاست unless-stopped؛ سرویس‌های اصلی فعال. پایش خودکار هفت مسیر HTTP200.
- آزمون پس از سخت‌گیری جدید مرز دایرکتوری: Apache/FPM واقعی از socket activation پاسخ PHP (fpm-fcgi)، FrankenPHP پاسخ PHP از socket اختصاصی. هر دو /.env و فایل backup پاسخ 403؛ دسترسی nobody از سوکت رد. حساب، enrollment و فایل‌های مصنوعی پاک شدند.
- Image محلی از انتشار GHCR با کاربر 10001:10001 و شبکه none، rootfs فقط‌خواندنی، سقف RAM 96MiB/CPU 20%، PING/SET/GET و port=0 تأیید؛ کانتینر موقت حذف شد. دانلود مستقیم قبلاً timeout داشت؛ export/load قبلاً انجام شده بود.
- اتصال Valkey تولید به WordPress: wp_using_ext_object_cache فعال، SET/GET بین پردازش‌ها و حذف کلید آزمایشی موفق. Redis اصلی دست‌نخورده. هشدار ionCube تکراری PHP 8.1 از قبل وجود دارد.
- سه سایت نمونه از مسیر عمومی HTTP200؛ RAM available 1805MiB، Swap free 1428MiB، دیسک حدود 11GiB آزاد. این snapshot پس از آزمون است، نه benchmark سرعت.
- Apache/FrankenPHP صفر enrollment واقعی. مسیر عمومی، provisioning تراکنشی از Create Website، TLS/header trust، DB/storage و بررسی کامل جداسازی هنوز تأیید نشده‌اند. PHP-FPM 8.1 استخراج‌شده نیاز به چرخه به‌روزرسانی امنیتی دارد. Ubuntu جدید و ZSTD مهاجرت/ارزیابی نشده‌اند. 
- مالک ریبوت را پس از تکمیل همه مراحل خواسته؛ شرط تکمیل عمومی هنوز برقرار نیست. ریبوت در این مرحله اجرا نشده. کنسول مستقل ارائه‌دهنده از طریق MCP قابل تأیید نیست. Plan B هنوز local listener است و جایگزین مستقل قطعی MCP نیست.
- وضعیت: اعتبارسنجی اجزای نصب‌شده موفق، انتشار توسعه‌ای؛ نه تأیید تکمیل کل زیرساخت یا استقرار عمومی موتورهای جدید.
