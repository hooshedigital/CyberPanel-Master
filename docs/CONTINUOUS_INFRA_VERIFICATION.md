# Continuous verification — release infrastructure branch
Run the full existing master extension safety suite on release preview pushes affecting master_extensions, infra/runtime or infra/ingress and on relevant PRs. Preserve existing branch coverage, read-only workflow permissions and test command. Add the capacity summary template to the capacity-panel workflow path filter so template-only changes trigger the existing contract tests. These are hosted CI checks, not production commands or a mandatory merge gate; no change to server services, protected branches, credentials or deployments. Existing Valkey build and publish workflow path filters already restrict pushes to changes in their own workflow files; leave them unchanged. No claims of CPU or disk savings from this CI configuration alone.
