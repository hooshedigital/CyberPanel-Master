# پنل وضعیت موتور وب مستقل
بخش فقط‌خواندنی مدیر در Create Website، با منابع زنده از procfs و statvfs. بدون subprocess، شبکه، نصب یا POST جدید. ظرفیت اولیه موتور ترکیبی: RAM available >=1408MiB، Swap free >=1024MiB، دیسک >=8192MiB، CPU PSI60 <40 و memory PSI60 <5. این معیارها صرفاً برای برنامه‌ریزی هستند. هیچ موتور جدیدی با این بخش ایجاد نمی‌شود. شرط Premium و مسیر اصلی ساخت سایت بدون تغییر می‌ماند.
ادغام نصب: در WebsiteManager.createWebsite پس از ساخت Data و پیش از httpProc، فقط برای مدیر، panel_context(currentACL) اضافه شود؛ template مستقل در app websiteFunctions قرار گیرد و قبل از Additional Features با include فراخوانی شود. در صورت خطا، context حذف شده و مسیر اصلی حفظ شود. بکاپ و rollback هر سه فایل پیش از تغییر لازم است. راه‌اندازی پنل در صورت نیاز؛ نه وب‌سرور سایت‌ها.
